To let someone in, the owner opens **Users** and, under **Create OS user**,
enters a **System username** and an **Initial password**, then chooses
**Create**. Give the person their username and password yourself, not in a
chat or a project file.

**Disable** removes someone's access; their name stays in the list.

There is no need to add anyone for this lesson.

```beats
show manage-users: Create a user here when you want someone to join.
```
