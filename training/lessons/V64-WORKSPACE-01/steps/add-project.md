In Develop, the workspace owner starts a new project with **Add project** on
the Projects page:

1. Give the project a name and choose **Continue**.
2. Choose where its code lives: **On Vibe64's server** needs no other account;
   **On GitHub** uses a repository on your GitHub account.
3. Open the new project and start building in its chat.

Add project is hidden in Learn, where lessons make their own practice
projects. Team members get practice projects by starting lessons; only the
owner adds workspace projects.
